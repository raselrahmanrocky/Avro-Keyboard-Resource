# Font licenses / ফন্ট লাইসেন্স

The fonts in [`../Fonts/`](../Fonts/) are the same free Bangla fonts the
Avro Keyboard installer has always bundled. They are **not** covered by the
repository's MPL 2.0 license — each font stays under the terms of its own
author.

[`../Fonts/`](../Fonts/-এর ফন্টগুলো Avro Keyboard ইনস্টলারে বান্ডিল করা
বিনামূল্যের বাংলা ফন্ট। এগুলো MPL 2.0 লাইসেন্সের আওতায় আসে না — প্রতিটি
ফন্ট তার লেখকের নিজস্ব শর্তাবলিতে বিতরণ করা হয়।

| ফাইল | ফন্ট | লেখক / উৎস |
|---|---|---|
| `kalpurush.ttf` | Kalpurush (Unicode) | Mizanur Rahman (Kalpurush) |
| `kalpurush ANSI.ttf` | Kalpurush ANSI | Mizanur Rahman (Kalpurush) |
| `Siyamrupali.ttf` | Siyam Rupali (Unicode) | Siyam Rupali project |
| `Siyam Rupali ANSI.ttf` | Siyam Rupali ANSI | Siyam Rupali project |

দয়া করে মূল ফন্ট প্রকল্পের সাইট থেকে সর্বশেষ লাইসেন্স ও সংস্করণ দেখে
নিন; প্রয়োজন হলে ফাইলটি এখান থেকে সরিয়ে দিন।

If you are a font author and want a file removed or the attribution corrected,
please open an issue in this repository.
